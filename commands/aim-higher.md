Aim higher — standalone, outside the lifecycle: it gates nothing and advances no stage.

Run `aim-higher` on the goal given as the argument, or the one in the conversation. It returns one short
goal block ready to set — or, for a goal already sized right, the person's own words.

Writes no file. Set the goal yourself, or hand it to `/ideate`, `/gauntlet-loop` or a
run's brief.
